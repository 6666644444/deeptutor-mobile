# 移动学习界面

## 方案取舍（2026-11-10）

当前是 Expo 57 / React Native 0.86 的独立原生客户端，已有统一控件、Ionicons、键盘避让、安全区域和内容排版。界面通过 API / WebSocket 调用服务，不承载原版网页。

| 方案 | 可取之处 | 接入成本与本轮决定 |
| --- | --- | --- |
| [React Native Paper](https://oss.callstack.com/react-native-paper/) | Material 3 的按钮层级、卡片、选中状态和无障碍交互 | 最接近现有需求；参考交互规范，本轮不引入依赖，也不复制组件源码 |
| [Tamagui](https://tamagui.dev/docs/intro/introduction) | 跨平台主题、响应式组件 | 需要接入其配置、Provider 和样式体系，与当前共享控件重复；暂不采用 |
| [gluestack UI](https://gluestack.io/ui) | 可按需引入并自行维护的组件 | 要承担组件和样式工具链维护；本轮暂不采用 |
| 现有原生共享控件 | 已覆盖业务屏幕，无新依赖 | 统一改进按钮、选项、标题、输入和列表，保留原生运行环境，便于兼容 OTA |

这些是架构取舍，不代表上述第三方库已在本工程安装或完成兼容性验证。后续引入新库仍需独立核对 Expo 版本及原生指纹。

## 预设来源与保存方式

- 官方 v1.7.1 的[出题面板](https://github.com/HKUDS/DeepTutor/blob/v1.7.1/web/components/quiz/QuizConfigPanel.tsx)提供出题方式、难度和题型选择；客户端保留已有方式及难度，并补自动难度和常用数量按钮。
- 官方[图示面板](https://github.com/HKUDS/DeepTutor/blob/v1.7.1/web/components/visualize/VisualizeConfigPanel.tsx)中 `style_hint` 是自由输入，并无固定讲解风格列表。
- “一步一步讲、生活例子、先提示再解答、图文少字”是**本客户端新增的文字快捷项**，不是官方新增能力，也不是保证输出形式的强制开关。选中后通过原有字符串字段发送。
- 快捷项覆盖动画/图示风格、个人讲解偏好、工作区学习要求；个人年级、阅读情况和学习书适合年级也可选择。题目、学习目标、教材名称等开放内容仍可输入。
- 未指定保持空字符串；打开表单不默认覆盖旧资料；已有自定义值完整显示；只有点击完成/保存后才生效，取消不保存。

## 统一交互

- 主按钮用实色，辅助按钮用浅色边框，删除用红色；可点击区域至少 44 点，提供按下、禁用和选中状态。
- 聊天工具区区分模型/学习方式与拍照/相册/文件，当前模型另行展示，避免长模型名称挤坏按钮。
- 输入时收起多排工具与标题副说明，标题暂时显示一行，为上一条回复和发送按钮保留空间；点击“学习工具”收起键盘，恢复完整标题和全部操作，输入草稿保持。
- 标题不按字符数量强制截断，随容器宽度和系统字号换行；标题空间不足时，表单操作另起一行。
- 保留键盘避让、独立账号、资料保存、模型切换和自定义配置；中文为当前界面语言。
- 手动编辑服务地址时暂停后台重连，避免失败重试将输入恢复为旧值；未进入编辑页的离线会话仍可自动恢复。

发布前须在 Android 实际操作表单选择、取消、保存、重新打开、长标题和键盘；合成服务验证不能替代真实 VPS 的模型输出验收。
