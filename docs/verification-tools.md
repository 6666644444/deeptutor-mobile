# 独立验收工具

客户端源码、原生模块和构建入口统一在本仓库维护。移动整个仓库目录后，从新目录执行命令即可；项目路径由脚本自身位置解析，不依赖旧工作区。

## 安卓文件分享来源

`python3 scripts/build-share-fixture.py --output-dir <仓库外的临时目录>` 构建独立测试发送 App，不会安装它或发布它。需配置 Android SDK 与 JDK 17/21；脚本复用现有开发环境发现逻辑，使用临时测试签名，和正式客户端签名无关。

测试界面提供单文件、多文件、中文文件名、超限文件、云文档链接和“其他应用打开”入口，真实传递 `content://` 的临时读取权限。内容全部是合成测试文件。安装到指定模拟器后，选择 DeepTutor 作为接收方，再验证确认、取消、账户隔离与上传结果；构建成功本身不是分享功能验收。

## 指定服务的接口核查

`scripts/verify-native-api.py` 是可选的接口验收工具，需要独立 Python 环境中的 `httpx`。须明确设置 `DEEPTUTOR_TEST_SERVER`、`DEEPTUTOR_TEST_USER`、`DEEPTUTOR_TEST_PASSWORD`、`DEEPTUTOR_TEST_REPORT`，以及 `DEEPTUTOR_TEST_ALLOW_WRITES=yes` 才能运行。

它在指定测试账号中创建合成阅读资料、笔记、日历事件、写作文档、学习目标和伙伴，并把新建 ID 记入报告。只用于可丢弃测试账号，不能对孩子账号或正式资料运行。它不会自动删除这些记录，也不会代表模型质量或全部客户端交互已通过。不要把凭据或报告提交到仓库。

任一检查失败时，脚本以非零状态退出；具体结果保存在指定报告中。

不需要真实服务写入时，使用 `scripts/mock-service.mjs` 和 `npm test`。账号身份校验、离线写入、会话恢复及跨账号请求隔离继续由当前测试集覆盖。
