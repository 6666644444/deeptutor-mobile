# DeepTutor 1.7.1 与移动客户端

依据是官方 [v1.7.1 发布说明](https://github.com/HKUDS/DeepTutor/releases/tag/v1.7.1)及该标签源码，核查日期为 2026-11-08。此文只说明版本增量；全部页面仍以[功能覆盖表](feature-coverage.md)为准。

| 官方变化 | 移动端设计与处理 |
| --- | --- |
| 账号字号、行距 | 我的 → 阅读显示，设置同步到当前服务器账号；正文与公式使用同一字号。PDF 原页仍通过缩放阅读。 |
| 修改密码、临时密码提示 | 我的 → 账号与学习资料；服务器允许时显示改密表单和初始密码提示。成功后同步本机安全存储中的自动登录信息，错误不覆盖旧凭据。 |
| 未发送和创建草稿 | 聊天、学习创建页保留文本和选择；聊天同时保留附件。按服务、账号、工作区和页面隔离，离开或进入后台保存；服务器确认接收后清除对应聊天草稿。保存失败提示并保留原记录。 |
| Little Tutor 来源恢复、移动与清除 | 消息 → 单独追问；追问页可以返回原对话、更换来源或改为整段对话。聊天的“单独追问”列表继续已有线程，保留原记录。 |
| 修改/重发跟随当前模型和语言 | 消息 → 修改后再问，可不改文字直接再次提交；发送时重新解析当前模型，使用中文回复。保留原消息与回答，通过版本按钮切换，不把两条分支拼成一段。 |
| 生成文件的打开与下载 | 文件卡片支持 PDF 分页原生预览、文本查看，以及系统文件保存/分享；使用当前账号鉴权，跨来源地址不携带账号。 |
| Anki 与 iCalendar | 写作与笔记内导出全部或单篇闪卡为 Anki 文本；学习日历原有 ICS 导出继续保留。 |
| 视频课程配音/检查/修复，数学动画干运行检查 | 继续调用对应能力。检查、TTS 回退、修复属于服务端执行，结果仍经自己的移动播放器/内容卡展示。不能据此承诺服务端已安装全部生成依赖或配置付费服务。 |
| 模型、搜索、语音及网关扩展 | 模型列表来自服务端，保留模型选择和个人 Key 扩展；无需在客户端写死新增服务商列表。非对话服务的配置仍受服务端能力与权限限制。 |
| 文档、索引、检索、取消可靠性 | 由目标服务端版本提供，沿用现有 API 与任务恢复。没有把桌面 Python/Node 运行时移植进手机。 |
| 桌面发行与更多界面语言 | 桌面安装包不属于移动功能；客户端按当前产品要求保留简体中文，不新增语言切换。 |

草稿存储在本 App 的私有文件目录，附件不会传给 GitHub 或其他服务器。草稿不是跨设备云同步，也不等同于服务器已保存的学习记录；卸载或清除 App 数据会失去本机未发送草稿。

本轮真实服务测试使用授权测试账号和合成题目，覆盖字号回读、Anki 导出、实际模型回答、编辑保留分支、追问来源恢复/移动/解除及临时资料清理。自动检查、Android/iOS 实际运行范围另见[验证记录](validation.md)，不得把接口测试替代移动端验收。
