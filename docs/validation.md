## Android 交互

使用独立 Android 36.1 arm64 模拟器、Metro 8086 和本机虚拟服务。测试不是实际模型质量或完整后端验收。

| 场景 | 实际结果 |
| --- | --- |
| 启动与页面 | 首页、错题、资料、我的正常打开；错题空状态没有旧 `filter` 崩溃。功能列表和工作区入口进入客户端页面；空状态不等于业务流程验收。 |
| PDF 与内容画布 | 虚拟 PDF 原页和文字阅读正常；分数公式、Mermaid 流程图、Chart.js 图表实际显示，图表展开/关闭正常。 |
| 流式聊天 | 虚拟服务 `render` 回复正常完成；修复后没有再出现完成后的连接中断提示。 |
| 登录与键盘 | 手动退出后重新登录成功；密码输入时可以滚动并点击登录按钮。模拟器 Gboard 首次引导关闭后输入正常。 |
| 服务切换与恢复 | 认证服务甲切到乙，资料仅显示乙的标签；冷重启后恢复乙及账号。再切免登录服务，身份改为单用户空间；冷重启后仍恢复该服务，没有残留登录账号。 |
| 表单及失败提示 | 笔记本新建可输入、取消、返回；虚拟服务未实现的保存显示中文“此内容不存在、当前账号不可访问，或服务未安装此功能。”，页面没有崩溃。未把该拒绝结果算成真实保存成功。 |

有限日志观察中未捕获 JavaScript 异常或应用原生崩溃；这不代表全部场景均无错误。PDF、聊天与身份切换使用虚拟资料；本轮没有对真实模型、真实导入或全部 CRUD 做端到端验收。

## 明确限制

未验证本版真实服务器全量 API、真实模型/OCR质量、长期后台任务、所有第三方分享来源、所有文档格式、iOS 真机或 Windows 构建。iOS 模拟器构建成功不能替代分享 App Group 的真机签名与运行验收。没有公开 APK/IPA、OTA 或 TestFlight 交付。

尚未完整移植的高级工作流见 `native-migration.md`。服务器没有配置模型时，对应任务不能因入口存在就算可用。PDF使用原生阅读器，数学/图表使用隔离内联 WebView；不加载上游应用页面。

旧错题 `items/filter` 崩溃已在迁移中修正模拟服务返回并加入客户端响应校验；自动测试覆盖原始错误形态，安卓本版已进入错题空状态。此前 0.1.0 的内嵌页面验收不适用于本版已移除的架构。
