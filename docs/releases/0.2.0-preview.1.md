# 0.2.0-preview.1

首次原生客户端源码预览，适配 DeepTutor 1.7.1。

- 学习模块改为客户端页面，新增 PDF 阅读、文件分享收件箱及公式/图表显示。
- 保留电脑/服务器连接、自动登录和服务、账号、工作区隔离。
- 修复错题列表异常响应崩溃和聊天结束后的误报。

33 项自动测试、Android 与 iOS 模拟器构建通过；Android 完成部分交互回归，iOS 尚未完成交互验收。详见[验证记录](https://github.com/TinyPandaGame/deeptutor-mobile/blob/v0.2.0-preview.1/docs/validation.md)。

附件提供源码、文件清单和 SHA256，需自行构建并连接兼容服务。功能范围见[说明](../native-migration.md)，已知依赖风险见[安全审计](../security-review.md)。
