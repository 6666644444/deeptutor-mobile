# 0.2.0-preview.1 — 原生重构源码预览

客户端现在使用自己的页面承载学习功能，通过用户选择的 DeepTutor 服务 API / WebSocket 读取数据和调用能力。旧模块路由转到原生功能页，移除了上游应用网页和凭据注入。

## 主要变化

- 迁入阅读、知识库、书籍、精通学习、笔记、写作、伙伴、记忆、日历及工作区流程，增强聊天能力选择、附件和互动题卡。
- 保留“连接我的电脑 / 连接服务器”、免登录与认证模式、自动恢复；将新增功能接入服务＋账号＋工作区隔离。
- 增加原生 PDF、外部文件分享收件箱和用户主动导出。PDF/媒体/导出使用当前连接，拒绝跨源地址，切换时取消旧请求和清理临时文件。
- 增加离线公式和图表渲染。数学/图表仍使用隔离的内联 WebView，不能称为完全没有 WebView。
- 修正错题列表不兼容响应导致的 `items/filter` 崩溃；恢复流式完成后忽略迟到连接错误的保护。

## 验证

独立公开工程的应用/测试 TypeScript、ESLint 和 33 项自动测试通过。干净源码副本 `npm ci`、离线资源重新生成和上述检查通过；Android arm64 Debug 与 iOS Simulator Debug 构建通过。Android 的实际交互覆盖范围见 [validation.md](../validation.md)。iOS 本版没有完成交互或真机验收。

## 使用与限制

这是源码预览，附件是源码包、文件清单和 SHA256；不包含公开签名 APK/IPA。先阅读 README 的工具链与运行步骤。`npm ci` 会从锁定依赖生成离线内容资源；源码包不含 node_modules、生成的原生工程、私人配置、学习资料或签名材料。运行真实学习任务需要自行部署并配置兼容的 DeepTutor 1.7.1 服务。

本版不等于桌面 100% 功能等价。伙伴外部渠道/群聊、部分写作讨论/复习卡、精通地图手工管理、知识库同步源和管理员模型/工具管理等仍有缺项。EPUB为提取文本/插图，日历提醒不是本地通知，未部署 OTA。真实 OCR、全部分享来源、复杂长任务及服务端所有生成器尚未完整验收。

当前 npm audit 有 32 个受影响依赖条目：5 high、23 moderate、4 low、0 critical。没有通过无漏洞门槛；详见安全审计文档。未用跨 Expo 主版本的强制升级掩盖这些问题。
