# 0.3.0-preview.4

补齐 DeepTutor 1.7.1 中面向移动学习的新增操作，继续使用自己的中文原生界面和 API，不嵌入官方应用页面。

- 账号改密、初始密码提示，以及修改后本机自动登录信息同步。
- 账号级字号、行距设置，正文和公式一起调整。
- 聊天与学习创建草稿恢复，附件按账号、工作区隔离保存。
- 修改历史问题后用当前模型重新回答，保留原分支；管理单独追问的来源。
- 生成文件查看、PDF 分页与系统分享；笔记闪卡导出 Anki。

原生基础版本 0.3.0，Android versionCode 5，iOS 工程 buildNumber 5。提供通用 arm64 APK 与不含私人签名的 Xcode 工程，用户填写自己的电脑或服务器地址。iOS 工程需使用自己的 Apple 团队构建，不代表提供通用 IPA 或 TestFlight。

具体覆盖和限制见 [1.7.1 对应说明](../upstream-1.7.1.md)、[验证记录](../validation.md)。热更新只读取本客户端仓库；是否可自动下载取决于该平台和安装包 runtime 是否有通过验收的签名清单。源码、APK 或工程附件本身不等于已下发 OTA。
