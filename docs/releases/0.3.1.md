# 0.3.1

继续适配 DeepTutor 1.7.1，本次为客户端修复与体验优化。

- 聊天中直接拍照或从相册选图，发送前显示预览；即时消息和服务器请求使用同一附件列表，修改问题再发送也保留原附件。
- 向上看题目和照片时停止自动跟随回复，图片加载或公式排版变化不再强制跳到底部；回到底部后恢复跟随。
- 点击聊天照片查看原图；历史照片加载失败可重试。图片仍通过当前账号、工作区的同源认证下载。
- 回复改为适合手机的短段落、小标题和列表；表格按条目阅读，Markdown 标记不直接展示。
- 公式保留分数、乘除号等数学意义；流式未完成的公式显示生成提示，排版失败不暴露 TeX 错误代码。代码示例和货币符号保持原意。
- 采用纯数字版本：同上游版本下修复增加 Z；适配新的官方版本增加 Y、Z 归零。规则与维护命令见[版本说明](../versioning.md)。

原生基础仍为 0.3.0（构建 5）。没有新增原生依赖、权限或修改签名；双端 runtime 与 preview.4 相同。OTA 必须由发布流程对 Android / iOS 各自验收、签名后下发，安装包构建成功不等于已公开热更。

提供通用 arm64 APK 与不含私人签名的 iOS 工程。iOS 用户使用自己的 Apple 团队构建；本次不包含个人 TestFlight 上传。

测试范围和 iOS 模拟器相机限制见[验证记录](../validation.md)。
