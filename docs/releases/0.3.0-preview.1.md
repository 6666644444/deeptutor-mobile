# 0.3.0-preview.1

加入从本仓库 GitHub Releases 分发签名热更新的基础能力。

- 兼容更新自动下载，用户重启后生效；失败时保留当前版本。
- 原生加载器校验签名、资源哈希和运行时，保留嵌入版本与启动回退。
- 更新检查不携带学习服务凭据，不需要 VPS 更新接口或 EAS 托管。

58 项自动测试通过。Android 已通过本机模拟分发源的签名拒绝、下载和重启验收；iOS 仅通过模拟器构建。

**仅发布源码，无公开 OTA 清单或安装包。** 公开 GitHub OTA 和 iOS OTA 运行尚未验收；旧安装包需先安装包含更新模块的新基础包。详见[更新说明](../updates.md)。
