# 0.3.2

修复使用 Xcode 27 构建的 iOS 客户端在 iOS/iPadOS 27 上打开即退出的问题。启用官方 UIScene 启动支持，并在 iOS 构建、工程导出流程加入启动配置校验。

本次仍适配 DeepTutor 1.7.1。原生基础版本 0.3.2、构建号 6；iOS 需要更新完整安装包，OTA 不能修复旧包缺失的启动配置。自行签名的使用者需下载新工程并重新构建。

公开 iOS Release 包已在 iPadOS 27 模拟器验证冷启动、登录与草稿恢复、前后台切换、深链和更新查询；Android 正式签名包覆盖安装保留登录与草稿。82 项 Node 测试和 8 项 Python 构建检查通过。

本次双端原生运行时均已改变，请先安装完整新版；兼容热更新只接受与新基础包实际运行时一致的签名清单。真机、相机和外部 App 分享导入未在本轮验收，详细范围见[验证记录](../validation.md)。
