# 0.3.0-preview.2

新增对话模型切换与模型、API Key 管理。

- 每轮提交实际模型 ID，恢复历史选择，修正切回默认模型的行为。
- 普通账号可发现或手动添加模型、替换 Key、设置默认及删除个人配置；需要安装 [DeepTutor 1.7.1 可选扩展](../../server/README.md)。
- 管理员可管理共享模型与服务商；编辑密钥优先使用模型自身绑定的服务商。

64 项客户端测试、7 项服务端隔离测试通过。Android 已验收模型选择、Key 表单和授权测试服务的一轮模型回答。

仅发布源码。本轮未验收 iOS、真实个人 Key 的付费推理或公开 OTA；原生基础版本仍为 0.3.0。功能缺口与测试范围见[验证记录](../validation.md)。
