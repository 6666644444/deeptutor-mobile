# 0.3.0-preview.3

提供通用 Android 安装包与可自行构建的 iOS 工程，首次填写自己的 DeepTutor 服务地址即可连接。

- **[Android 通用 APK（arm64）](https://github.com/TinyPandaGame/deeptutor-mobile/releases/download/v0.3.0-preview.3/deeptutor-mobile-0.3.0-preview.3-arm64-v8a.apk)**：独立安装，首次填写自己的电脑或服务器地址，保存后自动恢复连接。
- **[iOS Xcode 工程 ZIP](https://github.com/TinyPandaGame/deeptutor-mobile/releases/download/v0.3.0-preview.3/deeptutor-mobile-0.3.0-preview.3-ios-project.zip)**：包含公开源码与生成的工程；在 Mac 上运行 `npm ci` 和 `npm run prepare:ios`，使用 Xcode 配置自己的团队与 App Group，不是 IPA。
- **源码包与校验清单**：供复现构建和核对下载文件。

客户端连接自建 DeepTutor 1.7.1；个人模型 Key 管理需要[可选服务端扩展](../../server/README.md)。安装客户端不会部署学习服务器。

首次连接支持直接输入电脑 IP/端口或服务器域名，并保存主机供后续切换。私网地址默认补 `http://`，公网域名默认补 `https://`，显式 HTTPS 不降级。

原生版本为 0.3.0，Android versionCode 为 4。此版不包含公开 OTA 下发。附件 SHA-256、签名证书摘要及实际验收范围见[GitHub Release](https://github.com/TinyPandaGame/deeptutor-mobile/releases/tag/v0.3.0-preview.3)；iOS 工程不代表已发行 IPA、TestFlight 或通过商店审核。

使用方法见[安装与构建指南](../build.md)、[电脑接入](../connect-computer.md)和[服务器接入](../connect-server.md)。
